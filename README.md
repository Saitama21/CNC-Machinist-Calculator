# Инженерные инструменты

Отдельная офлайн-PWA с инженерными и точными цеховыми расчётами.

Основные инструменты:

1. Определитель резьбы по измеренному диаметру и шагу/TPI.
2. Подбор сверла под нарезание резьбы.
3. Расчёт геометрии профиля метрической резьбы.
4. Локальное избранное.
5. Быстрый справочник посадок, шероховатости и обозначений.
6. Геометрические калькуляторы: конус, шестигранник и поворот координат.

Точные расчёты v2.0:

7. Допуски ISO 286: предельные отклонения, диапазон и середина допуска.
8. Теоретическая шероховатость точения Ra/Rz по подаче и радиусу пластины.
9. Истинная позиция отверстия/вала с бонусом MMC.
10. Оценка прогиба расточной державки, сил резания и отношения L/D.

Цеховые расчёты v3.0:

11. Вес заготовки и партии для круга, трубы, шестигранника, прямоугольника и шара.
12. Болтовая окружность с координатами X/Y и копированием таблицы.
13. Теоретическое измерение метрической резьбы 60° по трём проволочкам.
14. Длина вершины сверла и полная требуемая глубина отверстия.
15. Основное время точения, сверления и отрезки.
16. Офлайн-диагностика семи распространённых видов износа пластины.

В v3.0 интерфейс оформлен в стиле технического чертежа: тёмный Liquid Glass, синие линейные SVG-иллюстрации и динамические схемы результатов. Все рисунки находятся внутри приложения и не требуют сети.

Расчёты выполняются локально. Инструменты шероховатости и прогиба дают инженерную оценку; фактический результат зависит от жёсткости станка, закрепления, инструмента и материала.

## Публикация на GitHub Pages

1. Создайте новый пустой репозиторий GitHub.
2. Распакуйте ZIP и загрузите **содержимое** папки в корень репозитория.
3. Откройте `Settings → Pages`.
4. Выберите `Deploy from a branch`, ветку `main`, папку `/(root)` и сохраните.
5. После публикации один раз откройте адрес приложения с интернетом.
6. На iPhone: Safari → «Поделиться» → «На экран Домой».

После первого полного открытия приложение и все справочные данные работают без сети. Данные избранного хранятся только на устройстве.

## Локальная проверка

Service Worker требует HTTP/HTTPS. Запустите в папке проекта:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.
